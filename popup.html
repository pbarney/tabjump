Using the popup

The key will open the popup.

  • Click a slot number to switch to the tab assigned to that slot.
  • Assign assigns the current tab to that slot.
  • Unassign clears that slot.
  • Clear All removes all slot assignments.

These shortcuts work only when the popup window is open.

Notes

  • Slot assignments will persist as long as the tab still exists, but closing an assigned tab will clear its slot.
  • Restarting the browser clears all slots.
  • Tree Style Tab users can enable slot badges in Options.
