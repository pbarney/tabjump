Overview

TabJump is a Firefox add-on developed by pbarney. It is designed to help users assign jump shortcuts to currently open browser tabs.

This privacy policy applies only to the TabJump Firefox add-on.

Data stored by TabJump

TabJump stores data locally in your browser using browser.storage.local.

When you assign a tab to a jump slot, TabJump may store the following information locally:

  • tab ID
  • window ID
  • tab title
  • tab URL
  • favicon image data
  • whether the tab is pinned
  • whether the tab is incognito or private
  • the time the tab was assigned
Why this data is stored

This information is used only to remember your tab assignments and related add-on settings.

Local storage only

TabJump does not transmit locally stored tab-assignment information to the developer, to Mozilla, to GitHub, or to any other server.

No network requests

TabJump does not make network requests.

No analytics

TabJump does not use analytics, telemetry, or tracking.

No crash reporting

TabJump does not send diagnostic data to a remote service.

No external APIs

TabJump does not use remote configuration or external APIs.

TabJump does not sell, share, transfer, or disclose user data.

Permissions

TabJump uses the following Firefox extension permissions only for the add-on’s stated functionality.

Permission Why it is used
tabs Used to read open-tab information needed for assigning and jumping to tabs, including tab IDs, titles, URLs, and window IDs.
storage Used to store tab assignments and settings locally in your browser.
menus Used to provide TabJump actions in Firefox context menus.
notifications Used to show optional desktop notifications related to tab assignments.

Private browsing

If TabJump is allowed to run in private browsing windows, it may store local tab-assignment information for tabs assigned while using private browsing, including the fact that the tab was marked as private or incognito.

TabJump does not transmit this information anywhere.

Data removal

You can remove TabJump’s locally stored data by using the add-on’s "Clear All Jump Slots" option, or by uninstalling the add-on from Firefox.

Website and support scope

This policy applies only to the TabJump Firefox add-on. It does not cover third-party websites, GitHub, GitHub Pages, email providers, Mozilla services, or other services outside the add-on.
